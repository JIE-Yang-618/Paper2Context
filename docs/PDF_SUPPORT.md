# PDF support matrix

| PDF characteristic | v0.1.0 |
|---|---|
| Born-digital single-column paper | Supported |
| Born-digital two-column paper | Best-effort |
| Mixed layouts | Best-effort |
| Scanned/image-only paper | Detected; OCR required |
| Password-protected PDF | May be unsupported depending on encryption |
| Equations | Text extraction only; spatial math semantics not guaranteed |
| Complex tables | Caption detection only |
| Figure images | Caption manifest; image export is not guaranteed |
